Will it work on every website?+

Unlocked restores common event-based and CSS restrictions. It can’t reveal inaccessible content or turn images and canvas elements into selectable text.

Chrome’s internal pages, the Web Store, built-in viewers, and local files are excluded. Some custom blockers may persist. If a website’s controls or copy formatting behave differently, pause the extension for that site.
